# Assignment-III

This assignment aimed to improve our understanding of JavaScript programming and user interface interaction. We created various JavaScript programs that involved array operations, object manipulation, DOM manipulation, and UI-based timer functionality using HTML, CSS, and JavaScript.

The goal of this assignment was to practice logic building and interactive web development.

Task 1: Find Second Largest Number

Objective

Find the second largest number in an array without sorting it.

How It Was Implemented

1. We created an array of numbers.  
2. We used two variables to store:  
   - The largest number  
   - The second largest number  
3. A loop went through each element of the array.  
4. If a number was larger than the current largest value, we updated the values.  
5. Finally, we printed the second largest number using "console.log()".

Task 2: Return Unique Elements from Two Arrays

Objective

Create a function that combines two arrays and returns only unique elements.

How It Was Implemented

1. We created two arrays.  
2. We combined the arrays using the "concat()" method.  
3. A new array was created to store unique elements.  
4. We used the "includes()" method to check if the element already existed.  
5. If the element was not present, we added it to the unique array.  

Task 3: Student Score Analysis

Objective

Analyze student data and find the student with the highest average score.

How It Was Implemented

1. We created a list of student objects.  
2. Each student object contained:  
   - Name  
   - Age  
   - Scores array  
3. A loop calculated the average score for each student.  
4. Another condition checked which student had the highest average score.  
5. We displayed the result in the console.  

Task 4: Countdown Timer

Objective

Create a one-hour countdown timer using HTML, CSS, and JavaScript.

How It Was Implemented

1. We created a separate HTML file to design the timer interface.  
2. CSS styled the timer display and buttons.  
3. JavaScript implemented the timer logic.  

Features Implemented

- Timer displayed in MM:SS format  
- Start button to begin countdown  
- Pause button to stop the timer temporarily  
- Reset button to restart the timer  
- Prevented the timer from going below zero  
- Displayed a message when the timer reached zero  

This assignment helped us strengthen our understanding of JavaScript fundamentals and UI interactivity. By completing these tasks, we gained hands-on experience in problem solving, DOM manipulation, and building interactive web components, which are essential skills for web development.
